☁️ Cloud Storage Opschaling (AWS S3)

Voor grootschalige medische portals worden foto-uploads en dossier-scans niet rechtstreeks op de webserver opgeslagen. Dit kan de schijfruimte van de server verstoppen en het opschalen lastiger maken.

Aanbevolen migratiestappen naar Amazon S3:

  1. Maak een AWS S3 Bucket aan (bijv. clinibook-sr-dossiers).
  2. Installeer de AWS SDK via npm: npm install @aws-sdk/client-s3.
  3. Wijzig de upload logica in routes/prescriptions.js om bestanden direct naar de S3 bucket te streamen en sla enkel de beveiligde S3 URL op in de MySQL-database (kolom file_path).
  4. Gebruik AWS IAM-rollen en gecodeerde URL's (Presigned URL's) zodat patiëntgegevens enkel via geautoriseerde verzoeken te downloaden zijn (i.v.m. medische privacywetgeving).
